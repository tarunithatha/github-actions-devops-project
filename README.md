# GitHub Actions DevOps Mini Project

This project demonstrates a simple CI/CD pipeline using GitHub Actions and GitHub Pages.

## Project Objective

To automatically validate and deploy a static website whenever code is pushed to the main branch.

## Tools Used

- GitHub
- GitHub Actions
- GitHub Pages
- HTML, CSS, JavaScript

## Workflow

1. Developer pushes code to the `main` branch.
2. GitHub Actions automatically starts.
3. The workflow checks whether required website files exist.
4. If validation passes, the website is deployed to GitHub Pages.
5. The live website is updated automatically.
